Because the project uses Relation::enforceMorphMap(), add TeacherAttendance to
the SAME existing morph map.

use App\Models\Attendance\TeacherAttendance;

Relation::enforceMorphMap([
    // keep all existing aliases...

    'teacher_attendance' => TeacherAttendance::class,
]);

Do not create a second enforceMorphMap() call if you already have one.

Verify:

php artisan tinker

(new \App\Models\Attendance\TeacherAttendance())
    ->getMorphClass();

Expected:

"teacher_attendance"

This alias is required because AuditLogger calls getMorphClass() for teacher
check-in/check-out audit records.
